# Airline Analytics Dashboard

## Executive Summary

This project presents a professional **Airline Analytics Dashboard** developed in **Power BI** to analyze airline ticket pricing, flight distribution, route popularity, stop patterns, and airline performance.

The dashboard transforms aviation and flight data into actionable business intelligence insights, enabling users to evaluate:

* Flight pricing trends
* Airline performance
* Popular travel routes
* Stop distribution analysis
* Quarterly pricing trends
* Route and destination analytics

The solution was designed to simulate a real-world airline business intelligence and aviation reporting system.

---

# Business Problem

Airline companies manage large-scale operational and pricing data across:

* Airlines
* Routes
* Destinations
* Ticket prices
* Flight durations
* Stop categories

Without centralized analytics, identifying profitable routes, pricing behavior, and airline performance becomes difficult.

This dashboard solves that challenge by providing an interactive and executive-level airline analytics platform.

# Dataset Information

The dataset contains airline and flight information including:

| Column       | Description            |
| ------------ | ---------------------- |
| Airline      | Airline company        |
| Source       | Flight departure city  |
| Destination  | Arrival city           |
| Route        | Flight route           |
| Price        | Ticket price           |
| Duration     | Flight duration        |
| Total_Stops  | Number of flight stops |
| Quarter      | Business quarter       |
| Flight_Count | Number of flights      |

---

# Key Insights

Some important insights generated from the dashboard include:

* TruJet recorded the highest airline activity.
* VAR–BHU emerged as the most popular route.
* Ticket prices varied significantly between airlines.
* Flights with multiple stops showed higher total pricing trends.
* Quarterly price trends peaked during Q3.
* Non-stop flights remained operationally efficient but limited in availability.
